# The Space Between

A tiny 3D sanctuary for slow moments. Wander the floating garden, gather its drifting lights, and plant them as flowers.

## Run locally

```sh
npm install
npm run dev
```

Use WASD or the arrow keys to move, drag to look around, and press Space to plant a collected light. Touch controls are available on smaller screens.

## GitHub Pages

After merging into `main`, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**. The deploy workflow builds the Vite app and publishes it to Pages on every push to `main`. You can also run it manually from the Actions tab.
